# Security policy

This repository contains security research: proofs of concept that demonstrate bugs in code I do
not own, and a testbed protocol that is explicitly not production software.

## Reporting a problem in this repository

If you find a bug in the tooling or in the testbed protocol here, open an issue. If it is a
security issue in a **third-party** project that one of these documents describes, do not open an
issue: report it to that project through its own disclosure channel first, and only reference it
here once it is public or fixed.

## What is not in scope

- The testbed protocol is unaudited and must not be deployed with real funds.
- Proofs of concept are written against pinned commits and blocks; they may not reproduce after
  those projects change.

## Contact

Open a private security advisory on this repository (Security → Report a vulnerability). Do not open
a public issue for an unfixed problem in someone else's code.
